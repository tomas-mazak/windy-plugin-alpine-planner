# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Report it privately through GitHub's
[private vulnerability reporting](https://github.com/tomas-mazak/windy-plugin-alpine-planner/security/advisories/new)
on this repository (the **Security** tab → **Report a vulnerability**).

Please include what you found, how to reproduce it and what an attacker could do with it. You'll get an answer as
soon as possible; once a fix is published, the report can be disclosed.

## Scope

Alpine planner runs inside Windy's web page as a plugin. Reports about the plugin's own code, its build and release
workflows, and its handling of the end-to-end test credentials are in scope. Problems in Windy itself should go to
Windy.

## Supported versions

Only the latest version published in Windy's plugin gallery is supported.
